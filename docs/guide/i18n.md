# 国际化

Apron Design Vue 目前使用中文作为默认语言。如果你需要支持其他语言，可以通过以下方式实现。

## 组件文本

部分组件包含内置文本，如 Modal 的确认/取消按钮、空状态的默认文案等。你可以通过 props 来覆盖这些文本：

```vue
<template>
  <Modal
    :open="open"
    title="Confirm"
    ok-text="OK"
    cancel-text="Cancel"
  >
    Are you sure?
  </Modal>

  <Empty description="No Data" />
  
  <Pagination
    :current="1"
    :total="100"
  />
</template>
```

## 常见文本对照

| 组件 | 属性 | 中文默认值 | 建议英文 |
| --- | --- | --- | --- |
| Modal | okText | 确定 | OK / Confirm |
| Modal | cancelText | 取消 | Cancel |
| Drawer | okText | 确定 | OK / Confirm |
| Drawer | cancelText | 取消 | Cancel |
| Empty | description | 暂无数据 | No Data |
| Select | placeholder | 请选择 | Please select |
| DatePicker | yearLabel | 年 | Year |
| DatePicker | monthLabel | 月 | Month |
| DatePicker | dayLabel | 日 | Day |
| PopoverConfirm | okText | 确定 | OK |
| PopoverConfirm | cancelText | 取消 | Cancel |

## 封装国际化组件

你可以封装一层组件来统一管理国际化文本：

```vue
<script setup lang="ts">
import { computed } from 'vue'
import { Modal as ApronModal } from '@apron-design/vue'
import { useI18n } from 'vue-i18n'

const props = defineProps<{
  open?: boolean
  title?: string
}>()

const { t } = useI18n()

const okText = computed(() => t('common.confirm'))
const cancelText = computed(() => t('common.cancel'))
</script>

<template>
  <ApronModal
    v-bind="props"
    :ok-text="okText"
    :cancel-text="cancelText"
  >
    <slot />
  </ApronModal>
</template>
```

## 与 vue-i18n 集成

如果你的项目使用 [vue-i18n](https://vue-i18n.intlify.dev/)，可以创建一个 composable 来简化使用：

```ts
// composables/useApronI18n.ts
import { useI18n } from 'vue-i18n'
import { computed } from 'vue'

export function useApronI18n() {
  const { t } = useI18n()

  return {
    modal: computed(() => ({
      okText: t('apron.modal.ok'),
      cancelText: t('apron.modal.cancel'),
    })),
    empty: computed(() => ({
      description: t('apron.empty.description'),
    })),
    // ... 其他组件
  }
}
```

}
