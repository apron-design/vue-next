# 介绍

Apron Design Vue 是一个基于 Vue 3 的现代化组件库，使用 TypeScript 和 SCSS 构建，提供 40+ 高质量组件。

## 特性

- 🎨 **精心设计** - 基于现代设计理念，提供简洁优雅的视觉体验
- 🌙 **暗黑模式** - 内置完整的暗黑模式支持
- 📦 **丰富组件** - 40+ 组件覆盖各种业务场景
- 🔧 **TypeScript** - 完整的类型定义
- 🎯 **按需引入** - 支持 Tree Shaking
- ⚡ **高性能** - 基于 Vue 3 Composition API

## 设计理念

### 简洁

我们相信简洁的设计能够帮助用户更好地聚焦于内容本身。Apron Design 的每个组件都经过精心设计，去除冗余的装饰，保留核心功能。

### 一致性

组件库遵循统一的设计语言和交互模式，确保用户在不同组件间切换时能够获得一致的体验。

### 可定制

通过 CSS 变量（Custom Properties），你可以轻松自定义组件的外观，以适应不同的品牌需求。

## 兼容性

- Vue 3.3+
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持 SSR
